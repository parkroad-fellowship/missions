## UI Elements Legend

- **Page Indicators**: Dots at top showing current page position
- **Close Button**: X button in top-left corner (appears after intro)
- **Swipe Gesture**: Left/right swipe to navigate
- **Animations**: 
  - Icons scale in with elastic bounce
  - Numbers count up/fade in
  - Cards slide up from bottom
  - Text shimmers for emphasis

## Interaction Patterns

1. **Entry Animation**: Celebration icon bounces in → Name fades up → Year slides in → Title scales up → CTA shimmers
2. **Page Transition**: Smooth horizontal slide between pages
3. **Stats Reveal**: Sequential appearance with staggered delays (200ms intervals)
4. **Highlight Cards**: Slide in from left after main stats appear
5. **Exit**: Tap close button or swipe back from first page

## Responsive Behavior

- Font sizes scale with device text settings
- Safe area padding for notched devices
- Maintains aspect ratios on different screen sizes
- Touch targets minimum 44x44 points

## Accessibility

- High contrast text (white on colored backgrounds)
- Semantic icons paired with text
- VoiceOver/TalkBack support through standard Flutter widgets
- Reduced motion support (animations still graceful but simpler)
